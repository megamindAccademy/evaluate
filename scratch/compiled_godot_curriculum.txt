Nodes: The Building Blocks
Nodes are the fundamental elements in Godot, 
representing specific functionalities like sprites, 
sounds, or physics objects. They are the atomic 
units of your game, each with its own properties 
and behaviors.
Scenes: Organizing Complexity
Scenes are collections of nodes arranged in a 
hierarchical structure. They allow you to create 
reusable, modular components of your game, 
from characters to entire levels.
Scene Tree: The Big Picture
The scene tree is the overall structure of your 
game, showing how different scenes and nodes 
are connected and interact with each other.
Inheritance: Power of Reusability
Scenes can inherit from other scenes, allowing 
you to create complex objects while maintaining 
a clean, organized structure and promoting 
code reuse.

• ADDING NODES
Start by clicking the '+' button in the Scene panel or using the "Add Child Node" option. Choose from 
a variety of node types like Sprite, Area2D, or KinematicBody2D to suit your game's needs.
• NAMING AND POSITIONING
Give your nodes descriptive names and arrange them in the Scene tree. Use parent-
child relationships to create logical groupings and establish inheritance.
• CONFIGURING PROPERTIES
Adjust node properties in the Inspector panel. Set positions, scales, and other attributes 
to define how each node behaves and appears in your game.
• ADDING SCRIPTS
Attach GDScript files to nodes to add custom behavior. Right-click a node and select 
"Attach Script" to create or link a script file.

GDScript is a high-level, dynamically typed programming language used in the Godot Engine. It is
designed specifically for game development and integrates seamlessly with Godot's features,
offering a simple and efficient way to write scripts for game logic, UI interactions, and more.
2. What is a Variable?
A variable is a named storage location in memory that holds a value, which can change during
program execution. Variables are fundamental in programming, allowing developers to store and
manipulate data efficiently.
3. Explain 3 primitive data types?
- Integer (int): Represents whole numbers, such as 10 and -5.
- Float: Represents decimal numbers, such as 3.14 and -0.5.
- Boolean (bool): Represents true or false values.

Game Art and Animation
Types of Sprites:
Sprites are 2D images or animations that represent objects in a game. 
They can be static or animated, used for characters, environments, and UI elements.
Game Art Style:
Game art style defines the visual appearance of a game, including colors, textures, and design
techniques.
Types of Game Art Style:
- Pixel Art: Uses small pixels to create images, common in retro games.
- 3D Art: Uses 3D models and rendering for realistic visuals.
- Vector Art: Uses scalable vector graphics for smooth and clean visuals.
- Hand-Drawn Art: Styled like traditional drawings.
- Low-Poly Art: Simplified 3D graphics with low polygon counts.
Animating Sprites for Movement:
Sprites are animated using multiple frames to create a smooth motion effect.
Frame Animation:
Frame-by-frame animation is used to create movement by displaying different images (frames) in
sequence.
Movement and Speed in Game:
Movement in games depends on frame rate and physics. Speed is controlled by updating the
sprite?s position per frame.
Questions & Answers:
1. What is art style?
Art style is the visual design approach used in a game, including color schemes, character designs,
and artistic techniques.
2. What type of art style are we aiming for in the game?
The choice of art style depends on the game's theme. For example, a retro game may use pixel art,
while a modern game might use 3D or hand-drawn styles.
=== Page 2 ===
3. Can you explain the steps to add an animated sprite and frames in a game?
   - Create or import a sprite sheet with multiple frames.
   - Load the sprite sheet into the game engine.
   - Define the animation sequence by setting frame order and timing.
   - Implement a loop to update the sprite frame at each time interval.
   - Integrate movement and physics if needed.
