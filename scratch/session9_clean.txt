define a class called Person that represents a person. The class has 
two attributes, name and age, which are initialized using the __init__() 
method with the given arguments.
The class also has a function called greet(), which prints a greeting 
message containing the person's name and age.
We then create an instance of the Person class called person1 and 
pass in arguments for name and age. 
We then call the greet() method to print a greeting message to the 
terminal.
