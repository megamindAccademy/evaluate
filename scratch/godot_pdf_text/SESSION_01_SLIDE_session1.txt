Scenes
Godot organizes your game into individual scenes, which 
can be combined to create the full game world.
Nodes
Nodes are the building blocks of your scenes, 
representing different game elements like characters, 
objects, or UI components.
Scripting
Godot's scripting system, using GDScript or other 
programming languages, allows you to add interactivity 
and logic to your game.
