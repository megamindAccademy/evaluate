Nodes: The Building Blocks
Nodes are the fundamental elements in Godot, 
representing specific functionalities like sprites, 
sounds, or physics objects. They are the atomic 
units of your game, each with its own properties 
and behaviors.
Scenes: Organizing Complexity
Scenes are collections of nodes arranged in a 
hierarchical structure. They allow you to create 
reusable, modular components of your game, 
from characters to entire levels.
Scene Tree: The Big Picture
The scene tree is the overall structure of your 
game, showing how different scenes and nodes 
are connected and interact with each other.
Inheritance: Power of Reusability
Scenes can inherit from other scenes, allowing 
you to create complex objects while maintaining 
a clean, organized structure and promoting 
code reuse.

• ADDING NODES
Start by clicking the '+' button in the Scene panel or using the "Add Child Node" option. Choose from 
a variety of node types like Sprite, Area2D, or KinematicBody2D to suit your game's needs.
• NAMING AND POSITIONING
Give your nodes descriptive names and arrange them in the Scene tree. Use parent-
child relationships to create logical groupings and establish inheritance.
• CONFIGURING PROPERTIES
Adjust node properties in the Inspector panel. Set positions, scales, and other attributes 
to define how each node behaves and appears in your game.
• ADDING SCRIPTS
Attach GDScript files to nodes to add custom behavior. Right-click a node and select 
"Attach Script" to create or link a script file.

Design Game Structure:
Plan your game's overall structure, identifying main components like players, 
enemies, and levels. Sketch out how these elements will interact within the 
game world.
Create Main Scenes
Develop separate scenes for major game elements. For example, create a 
"Player" scene with all necessary nodes and scripts, and a "Level" scene to 
house the game environment.
Build Hierarchies
Organize your nodes within each scene logically. Use parent-child relationships 
to group related elements and create efficient, modular structures.
Instance and Combine
Instance your created scenes within a main game scene. This allows you to bring 
all elements together while maintaining the ability to edit individual components 
separately.

FUNCTION BODY
Write the function's code block indented after a colon. Use the 'return' keyword to specify the function's 
output. Example: return attack_power - defense
FUNCTION DECLARATION
Use the 'func' keyword followed by the function name and parentheses. Optionally specify parameters 
and return type. For example: func calculate_damage(attack_power: int, defense: int) -> int:
CALLING FUNCTIONS
Invoke functions using their name followed by parentheses, passing any required arguments. For 
instance: var damage = calculate_damage(player.attack, enemy.defense)
BUILT-IN FUNCTIONS
Utilize Godot's extensive library of built-in functions for common tasks. These include node 
operations, math utilities, and engine callbacks like _ready() and _process(delta).
