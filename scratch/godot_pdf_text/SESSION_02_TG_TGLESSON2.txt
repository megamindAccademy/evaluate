Programming Questions and Agenda Explanation
1. What is GDScript?
GDScript is a high-level, dynamically typed programming language used in the Godot Engine. It is
designed specifically for game development and integrates seamlessly with Godot's features,
offering a simple and efficient way to write scripts for game logic, UI interactions, and more.
2. What is a Variable?
A variable is a named storage location in memory that holds a value, which can change during
program execution. Variables are fundamental in programming, allowing developers to store and
manipulate data efficiently.
3. Explain 3 primitive data types?
- Integer (int): Represents whole numbers, such as 10 and -5.
- Float: Represents decimal numbers, such as 3.14 and -0.5.
- Boolean (bool): Represents true or false values.
