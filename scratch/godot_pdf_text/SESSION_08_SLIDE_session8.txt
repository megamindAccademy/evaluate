Play Function
The play ( ) function initiates the playback of the audio 
stream attached to the AudioStreamPlayer2D node.
Stop Function
The stop ( ) function halts the playback of the audio stream 
associated with the AudioStreamPlayer2D node.

Create a Sound Effect
Choose a sound effect that you 
want to use for your game. For 
example, a jumping sound or a 
sound for collecting an item.
Import Sound Effect
Import your selected sound 
effect into your Godot project by 
adding it to the "Audio" folder in 
the "FileSystem" tab.
Connect Script
In the script of the character or 
object, use the play() function to 
play the sound effect when the 
corresponding action occurs.
Attach to Node
Attach an AudioStreamPlayer2D 
node to your character node or 
the game object associated with 
the sound effect.

Immersive Experience
