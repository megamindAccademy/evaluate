## 🚀 مميزات النظام والتصميم (Features)
- **🎨 هوية بصرية مبهجة (Orange & Blue Theme):** تصميم يعتمد على ألوان الأكاديمية الرسمية مع تقنية الزجاج الشفاف (Glassmorphism) وخلفيات فقاعية متحركة.
- **🎁 صندوق الدلع والتشجيع:** قسم تفاعلي يمنح الأطفال رسائل تشجيعية مخصصة مع إطلاق قصاصات ورق ملونة (Confetti) ونغمات صوتية احتفالية.
- **🎲 نظام الاختبارات العشوائية:** يقوم النظام باختيار نموذج اختبار عشوائي من بين عدة نماذج متاحة للمادة في كل مرة يدخل فيها الطفل، مما يمنع التكرار ويزيد التحدي.
- **⚡ تغذية راجعة فورية (Instant Feedback):** يحصل الطفل على تصحيح فوري لإجابته مع شرح مبسط للحل الصحيح (`explanation`) ونغمات صوتية تدعمه.
- **📱 تصميم متجاوب بالكامل:** يعمل بكفاءة عالية على أجهزة الكمبيوتر، الأجهزة اللوحية (Tablets)، والهواتف المحمولة.

├── quiz.js                    # ملف التفاعل الخاص بصفحة الاختبار (تحميل البيانات، تصحيح الأسئلة، والنتيجة)

## 📁 معمارية قاعدة البيانات (Database Architecture)
يعتمد النظام على معمارية ملفات JSON مرنة ونظيفة داخل مجلد `database/`، مما يجعل إدارة المحتوى وإضافة الأسئلة أمراً في غاية السهولة دون الحاجة لتعديل أكواد البرمجة.

كل مادة تمتلك مجلداً خاصاً بها (مثل `database/python/`) يحتوي على:

### 1. ملف `manifest.json` (العقل المدبر للمادة)
يحتوي على البيانات الأساسية وقائمة بملفات الاختبارات المتاحة:
```json
{
  "course_id": "python",
  "course_title": "بايثون (Python)",
  "recap_file": "recap.json",
  "quizzes": [
    "quiz1.json",
    "quiz2.json",
    "quiz3.json"
  ]
}
```

### 2. ملف `re`cap.json` (ملخص المادة مقسماً بالجلسات)
يحتوي على النقاط السحرية التي يتذكرها الطفل قبل الاختبار، مقسمة إلى جلسات (Sessions):
```json
{
  "course_title": "بايثون (Python)",
  "recap_title": "🐍 مراجعة سريعة لأبطال بايثون قبل التحدي!",
  "recap_subtitle": "تعال نتذكر معاً أهم الأشياء السحرية التي تعلمناها في كورس بايثون بأكاديمية ميجامايندز مقسمة حسب الجلسات:",
  "sessions": [
    {
      "session_title": "💡 الجلسة الأولى: أساسيات التحدث مع الكمبيوتر",
      "points": [
        {
          "icon": "🖨️",
          "title": "دالة الطباعة print()",
          "desc": "هي الطريقة السحرية التي نستخدمها لنجعل الكمبيوتر يتكلم..."
        }
      ]
    }
  ]
}
```

### 3. مجلد `quizzes/` (بنك الأسئلة)
يحتوي على نماذج الاختبارات (مثل `quiz1.json`). كل نموذج يحتوي على 5 أسئلة (أو أي عدد تريده) بالصيغة التالية:
```json
{
  "quiz_id": "python_quiz_1",
  "quiz_title": "تحدي بايثون الأول: الأساسيات السحرية",
  "questions": [
    {
      "id": 1,
      "question": "ما هي الدالة السحرية التي نستخدمها لطباعة نص على الشاشة في لغة بايثون؟",
      "options": [
        "echo('Hello')",
        "print('Hello')",
        "write('Hello')",
        "output('Hello')"
      ],
      "correct": 1,
      "explanation": "ممتاز يا بطل! دالة print() هي المسؤولة عن الطباعة وإظهار النصوص على الشاشة في بايثون."
    }
  ]
}
```
*ملاحظة: حقل `correct` يمثل رقم الإجابة الصحيحة في مصفوفة `options` (العد يبدأ من الصفر `0`).*

## ➕ دليل إضافة اختبار جديد لمادة حالية (Add New Quiz)
إذا أردت إضافة نموذج اختبار رابع لمادة بايثون مثلاً، اتبع الخطوات الثلاث البسيطة التالية:

1. قم بإنشاء ملف جديد باسم `quiz4.json` داخل مجلد `database/python/quizzes/`.
2. ضع بداخله الأسئلة والاختيارات بنفس البنية الموضحة في ملفات الاختبارات الأخرى.
3. افتح ملف `database/python/manifest.json` وأضف اسم الملف الجديد إلى قائمة `quizzes` ليصبح هكذا:
   ```json
   "quizzes": [
     "quiz1.json",
     "quiz2.json",
     "quiz3.json",
     "quiz4.json"
   ]
   ```
سيقوم النظام تلقائياً بإدراج الاختبار الجديد ضمن الاختيارات العشوائية التي تظهر للأطفال! 🎉

## 🚀 دليل إضافة مادة جديدة بالكامل (Add New Course)
لإضافة مسار جديد بالكامل (مثلاً: مادة **سكراتش Scratch**)، اتبع الخطوات التالية:

### الخطوة 1: إنشاء مجلد المادة في قاعدة البيانات
قم بإنشاء مجلد جديد باسم `scratch` داخل مجلد `database/` (`database/scratch/`).

### الخطوة 2: إنشاء ملفات المادة الأساسية
داخل مجلد `database/scratch/`، قم بإنشاء الملفات التالية:
1. **ملف `manifest.json`:**
   ```json
   {
     "course_id": "scratch",
     "course_title": "سكراتش (Scratch)",
     "recap_file": "recap.json",
     "quizzes": [
       "quiz1.json"
     ]
   }
   ```
2. **ملف `recap.json`:** ضع فيه ملخص الجلسات الخاص بمادة سكراتش.
3. **مجلد `quizzes/`:** أنشئ بداخله ملف `quiz1.json` وضع فيه أسئلة سكراتش.

### الخطوة 3: تفعيل المادة في الصفحة الرئيسية (`index.html`)
افتح ملف `index.html`، وابحث عن بطاقة مادة سكراتش (`<article class="quiz-card" id="cardScratch">`).
قم بتعديلها لتصبح رابطاً نشطاً (`<a>`) يشير إلى `quiz.html?course=scratch` مع تغيير الشارة إلى `badge-active`، كما يلي:

```html
<!-- Card 5: Scratch Quiz (Active Link) -->
<article class="quiz-card" id="cardScratch">
    <span class="card-badge badge-active">متاح الآن 🌟</span>
    <div class="card-icon icon-scratch">🐱</div>
    <h3 class="card-title">اختبار مادة سكراتش (Scratch)</h3>
    <p class="card-desc">
        تصميم الألعاب والقصص التفاعلية! أطلق العنان لخيالك واصنع لعبتك الأولى بكل سهولة ومرح.
    </p>
    <a href="./quiz.html?course=scratch" class="card-btn btn-active" id="btnScratch">
        <span>ابدأ التحدي والاختبار 🚀</span>
    </a>
</article>
```
تهانينا! لقد تمت إضافة المادة الجديدة وتفعيل اختباراتها بنجاح. 🏆

## 🎁 نظام الدلع والتشجيع (Gamification)
تم تضمين تقنيات تفاعلية متطورة ومباشرة داخل المتصفح لضمان تجربة مذهلة للأطفال:
- **المؤثرات الصوتية (Web Audio API):** يتم توليد نغمات احتفالية عند الإجابة الصحيحة ونغمات تنبيه لطيفة عند الإجابة الخاطئة برمجياً وبدون أي ملفات صوتية خارجية.
- **قصاصات الورق الملونة (JS Confetti):** تنطلق الألعاب والقصاصات الملونة في الشاشة عند الضغط على أزرار التشجيع، وعند الإجابة الصحيحة، وعند الوصول للنتيجة النهائية.
