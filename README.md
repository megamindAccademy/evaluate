# 🌟 بوابة أبطال ميجامايندز | Megaminds Academy Quiz & Evaluation Portal

بوابة تفاعلية، مبهجة، ومصممة خصيصاً لتناسب هوية **أكاديمية ميجامايندز (Megaminds Academy)** لتعليم البرمجة، الذكاء الاصطناعي، وعلوم الروبوتكس للأطفال والمراهقين. تهدف البوابة إلى تقديم مراجعات سريعة للمعلومات واختبارات تفاعلية ممتعة (MCQ) مع نظام تشجيعي مفعم بالحماس والدلع لأبطال المستقبل، بالإضافة إلى **بوابة تقييم احترافية للمهندسين المشرفين**.

## 🚀 مميزات النظام والتصميم (Features)
- **🎨 هوية بصرية مبهجة (Orange & Blue Theme):** تصميم يعتمد على ألوان الأكاديمية الرسمية مع تقنية الزجاج الشفاف (Glassmorphism) وخلفيات فقاعية متحركة.
- **📝 تسجيل بيانات الطالب:** يبدأ الاختبار بطلب اسم الطالب، المجموعة، واسم المهندس المشرف، لضمان تخصيص الترحيب والمتابعة الدقيقة.
- **💻 دعم المهام البرمجية المفتوحة (Task-based Questions):** محرر أكواد ذكي ومخصص يتيح للطالب كتابة أكواد برمجية حرة ليقوم المهندس بمراجعتها لاحقاً.
- **🎁 صندوق الدلع والتشجيع:** قسم تفاعلي يمنح الأطفال رسائل تشجيعية مخصصة مع إطلاق قصاصات ورق ملونة (Confetti) ونغمات صوتية احتفالية.
- **🎲 نظام الاختبارات العشوائية:** يقوم النظام باختيار نموذج اختبار عشوائي من بين عدة نماذج متاحة للمادة في كل مرة يدخل فيها الطفل.
- **📱 تصميم متجاوب بالكامل:** يعمل بكفاءة عالية على أجهزة الكمبيوتر، الأجهزة اللوحية (Tablets)، والهواتف المحمولة.

## 👨‍🏫 بوابة المهندسين المشرفين (Engineer Portal)
تم استحداث بوابة مخصصة ومستقلة للمهندسين المشرفين (`engineer.html`) تتيح لهم متابعة وتقييم أداء الطلاب بكل سهولة واحترافية.

### 🔑 بيانات الدخول الافتراضية للمهندسين:
- **اسم المستخدم (Username):** `engineer` (أو `admin`)
- **كلمة المرور (Password):** `megaminds`

### 📋 مميزات بوابة المهندسين:
1. **🔍 البحث والفلترة الفورية:** شريط بحث سريع يتيح للمهندس البحث باسم الطالب، اسم المجموعة، اسم المهندس المشرف، أو حتى اسم المادة، مع فلترة الحالات (بانتظار التقييم / تم التقييم).
2. **📝 شاشة التقييم والمراجعة (Evaluation View):** تعرض بيانات الطالب كاملة، ونتائج أسئلة الاختيارات التلقائية (MCQ)، بالإضافة إلى الأكواد التي كتبها الطالب في أسئلة الـ Task.
3. **⭐ صندوق التصحيح اليدوي:** يتيح للمهندس إدخال الدرجة المستحقة للمهمة وكتابة الملاحظات والنصائح البرمجية المخصصة للطالب.
4. **🖨️ طباعة وتصدير التقارير (PDF Export):** زر مخصص لطباعة تقرير الطالب النهائي بتنسيق ورقي نظيف ومميز يخلو من الألوان والخلفيات الداكنة.

## 💾 معمارية قاعدة البيانات والتخزين السحابي (Database & Firebase)
يعتمد المشروع على **محول تخزين هجين فائق الذكاء (Hybrid Storage Adapter)** يجمع بين العمل المحلي الفوري والتخزين السحابي المجاني:

### 1. التخزين المحلي الفوري (LocalStorage Fallback)
يعمل النظام فوراً وبدون أي إعدادات مسبقة عبر `localStorage`. بمجرد أن ينهي الطالب اختباره في `quiz.html`، يتم حفظ إجاباته محلياً وتظهر فوراً في لوحة تحكم المهندس `engineer.html` على نفس الجهاز.

### 2. التخزين السحابي الفوري المجاني (Firebase Realtime Database)
لربط النظام ومشاركة الإجابات بين أجهزة الطلاب وأجهزة المهندسين عبر الإنترنت مجاناً وفي الوقت الفعلي (Realtime)، يمكنك تفعيل **Firebase Realtime Database** باتباع الخطوات البسيطة التالية:

1. اذهب إلى موقع [Google Firebase](https://console.firebase.google.com/) وقم بإنشاء مشروع جديد مجاني.
2. من القائمة الجانبية، اختر **Realtime Database** واضغط على **Create Database**.
3. اختر وضع الاختبار **Test Mode** (أو قم بضبط قواعد الأمان `rules` لتسمح بالقراءة والكتابة `.read: true, .write: true`).
4. اذهب إلى إعدادات المشروع (Project Settings)، وقم بإنشاء تطبيق ويب جديد (Web App) لنسخ كائن الإعدادات (`firebaseConfig`).
5. افتح ملف `engineer.js` (وكذلك `quiz.js` إذا أردت التزامن المباشر) وقم بلصق الإعدادات داخل كائن `FIREBASE_CONFIG` الموجود في أعلى الملف:
   ```javascript
   const FIREBASE_CONFIG = {
       apiKey: "AIzaSy...",
       authDomain: "your-project.firebaseapp.com",
       databaseURL: "https://your-project-default-rtdb.firebaseio.com",
       projectId: "your-project",
       storageBucket: "your-project.appspot.com",
       messagingSenderId: "123456789",
       appId: "1:123456789:web:abcdef..."
   };
   ```
بمجرد وضع الإعدادات وتحميل مكتبة Firebase، سيتحول النظام تلقائياً للعمل السحابي الفوري! ☁️🚀

## 💻 دليل إضافة أسئلة المهام البرمجية (Task Questions)
لإضافة سؤال يتطلب من الطالب كتابة كود برمجي حر (Task) بدلاً من الاختيارات التلقائية (MCQ)، كل ما عليك فعله هو إضافة السؤال داخل ملف الاختبار (مثل `quiz1.json`) وتحديد النوع `"type": "task"` مع تزويده بتلميح سحري `"task_hint"`، كما يلي:

```json
{
  "id": 6,
  "type": "task",
  "question": "تحدي البرمجة المفتوح (Task): اكتب كود بايثون يطلب من المستخدم إدخال اسمه باستخدام دالة input()، ثم يطبع له رسالة ترحيبية مبهجة باستخدام دالة print()!",
  "task_hint": "تذكر كتابة: name = input('ما اسمك؟') ثم print('أهلاً بك يا ' + name)",
  "explanation": "هذا التحدي يحتاج لإبداعك الخارق! تم تسجيل الكود الخاص بك في التقرير ليقوم المهندس المشرف بمراجعته وتقييمه قريباً."
}
```
سيقوم النظام تلقائياً بإخفاء أزرار الاختيارات وعرض محرر الأكواد الذكي للطفل! 🐍💻

## ➕ دليل إضافة اختبار أو مادة جديدة (Add New Content)

### 1. إضافة اختبار جديد لمادة حالية:
1. قم بإنشاء ملف جديد باسم `quiz4.json` داخل مجلد `database/python/quizzes/`.
2. ضع بداخله الأسئلة والاختيارات.
3. افتح ملف `database/python/manifest.json` وأضف اسم الملف الجديد إلى قائمة `quizzes`:
   ```json
   "quizzes": [
     "quiz1.json",
     "quiz2.json",
     "quiz3.json",
     "quiz4.json"
   ]
   ```

### 2. إضافة مادة جديدة بالكامل (مثل سكراتش Scratch):
1. أنشئ مجلداً جديداً `database/scratch/` وضعه بداخله ملفات `manifest.json` و `recap.json` ومجلد `quizzes/`.
2. افتح `index.html` وقم بتعديل بطاقة مادة سكراتش لتشير إلى الرابط `quiz.html?course=scratch` مع تغيير الشارة إلى `badge-active`.

## 🎁 نظام الدلع والتشجيع (Gamification)
تم تضمين تقنيات تفاعلية متطورة ومباشرة داخل المتصفح لضمان تجربة مذهلة للأطفال:
- **المؤثرات الصوتية (Web Audio API):** يتم توليد نغمات احتفالية عند الإجابة الصحيحة ونغمات تنبيه لطيفة عند الإجابة الخاطئة برمجياً وبدون أي ملفات صوتية خارجية.
- **قصاصات الورق الملونة (JS Confetti):** تنطلق الألعاب والقصاصات الملونة في الشاشة عند الضغط على أزرار التشجيع، وعند الإجابة الصحيحة، وعند إرسال الإجابات بنجاح.
